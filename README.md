# restoweb

Un site web est une présente notre restaurant.

## Fonctionnalités

- Interface de gestion de restaurant
- Application web conviviale
- Design moderne et responsive

## Démo

Visitez la démo en ligne : https://fastaze.github.io/restoweb/

## Installation

```bash
# Cloner le dépôt
git clone https://github.com/fastaze/restoweb.git
```

## Utilisation

1. Ouvrez votre navigateur web
2. Naviguez vers l'URL de l'application
3. Suivez les instructions à l'écran pour gérer votre restaurant
